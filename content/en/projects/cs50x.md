I'm working through [Harvard's CS50x](https://cs50.harvard.edu/x/), the introduction to computer science, as an online auditor. This page tracks which problem sets I've finished and what I take away from each one, with **no solution code at all**, in line with CS50's academic honesty policy, which prohibits making assessment solutions publicly available while enrolled.

The log below updates itself. It's fetched every time the site is built from a separate repo, [rubengariazzo-creator/cs50x-journey](https://github.com/rubengariazzo-creator/cs50x-journey), which only ever holds my progress and my personal reflections.
