## 第三方资源

除两种情况外，本网站的每个页面都只从 GitHub Pages 加载，而这两种情况都需要你主动点击才会触发。第一种：无人机救援游戏（在其项目页面上）会从公共 CDN `cdn.jsdelivr.net`（由 Volentio JSD Limited 运营）加载 Pyodide 运行环境（编译为 WebAssembly 的 CPython），这样该页面上展示的 Python 脚本才能真正在你的浏览器中运行。和从任何第三方服务器获取文件一样，这会让该 CDN 获得你浏览器通常的技术连接数据（包括你的 IP 地址），详见 [jsDelivr 隐私政策](https://www.jsdelivr.com/terms/privacy-policy)；该政策称其不使用 cookie，也不跟踪个人用户。只有当你选择打开并使用这个游戏时才会发生。第二种：伊卡洛斯（Icarus）项目页面上的两段视频托管在 YouTube（Google）上。只有在你点击它们的缩略图（由本站提供）之后，才会通过不使用 cookie 的域名 `youtube-nocookie.com` 加载；在此之前不会向 YouTube 发送任何请求。视频开始播放后，YouTube 会获得你浏览器通常的技术数据（包括你的 IP 地址），并可能设置 cookie，详见 [Google 隐私政策](https://policies.google.com/privacy)。除此之外，没有任何页面向 GitHub Pages 以外发出请求。

## 个人数据

本网站不设置任何非必要的 cookie，也不通过任何表单收集个人数据。它确实会出于纯功能性的目的使用你浏览器的本地存储（`localStorage`/`sessionStorage`），这些数据从不会传输到任何地方：记住当前会话中一次性的开场动画是否已经播放过；在会话期间记住光标的最后位置，用于一种装饰性的背景效果；记住你是否开启了可选的入侵者小游戏（默认关闭）；如果你开启它，则保存它的得分，以及 20 分奖励是否已经解锁。这些都不是个人信息或可识别身份的信息，你可以随时通过浏览器自带的网站数据设置清除所有这些数据。网站提供的联系方式是一个邮件链接（`mailto:`），它会打开你自己的电子邮件客户端，以及一个指向外部 LinkedIn 个人页面的链接；通过这些链接，网站本身不会传输或存储任何数据。

根据 GDPR，你可以通过写信到上述联系地址来行使你的权利（访问、更正、删除），并可向法国数据保护机构 CNIL（[cnil.fr](https://www.cnil.fr)）提出投诉。
